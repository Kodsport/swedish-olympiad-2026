\problemname{Compass Rotations}

You have a compass that can point in $360$ different directions.

At first, it points straight up, at the number $360$.

Unfortunately, the compass is broken, and the only way to get it to point in other directions is to lift the compass and rotate it a certainnumber of degrees counter-clockwise.

Luckily, you have two robot arms, where the first robot arm can rotate the compass $a$ degrees counter-clockwise, and the other robot arm can rotate the compass $b$ degrees counter-clockwise.

By using these robot arms as many times as you want, how many directions can the compass be pointed in?

\section*{Input}
Input consists of the integers $a$ and $b$ ($1 \leq a, b \leq 360$).

\section*{Output}
Print an integer: the number of unique directions the compass can be pointed in.

\section*{Scoring}
Your solution will be tested on a set of test groups, each worth a number of points. Each test group contains a set of test cases. To get the points for a test group you need to solve all test cases in the test group.
