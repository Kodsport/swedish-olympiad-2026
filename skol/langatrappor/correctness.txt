Note to reader: this is not formal, but should be good enough when combined with exhaustive stress-testing.

WLOG, swap start/goal such that we walk upwards (in direction of decreasing cost)

Lemma 1: no cycles.

This is well-known to hold for shortest paths with positive weights.

Lemma 2: per column, we only ever walk upwards in one segment, and possibly a single extra point

Proof: Assume it's cheaper to walk in two segments [a,b] (a<=b) and [c,d]. This means that we deviate
from b, travel some amount arbitrarily, then return c. Denote this walk by W. W pays some horizontal cost, and
some vertical cost. The only way for W to be cheaper is if the vertical costs are improved. However, if the
vertical costs are improved, this means that it gets to a cheaper column, so we might as well walk up to d there.
Since we are further up, the cost for walking back is even cheaper than walking back to c. This argument can be
repeated on an arbitrary set of intervals until we're left with one interval and a point.

Lemma 3: every path starts by increasing in y (possibly by nothing), then decreasing in y (possibly by nothing)

Proof: consider our height as a function. Suppose that there's a local minima. Then, we could choose to just
delete the downwards movements (and corresponding upwards), and end up with the same path with less cost. This is
because cells will have larger values down below.

Lemma 6: we never go much further than the goal's y

Proof: suppose we have same y as goal. We can pay some quantity x
to go straight into the goal
If we go up by 1, then x decreases by c, and we pay the value at that cell
So if our current cell is <= C, it might be profitable to go upwards. Otherwise, we instantly lose from it. But if our current cell value is <= C, then
we can only move upwards at most C times more.
