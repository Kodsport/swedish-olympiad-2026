\problemname{Frack Jack}
Alice and Bertil are playing a game in a park. There is a lamp post exactly 21 meters in front of them, and Jack gives them a challenge.

The challenge is for Alice and Bertil to each throw a ball as close to the lamp post as possible. However, the ball is not allowed to pass the lamp post.
The one who throws closest to 21 meters without exceeding it wins. If both Alice and Bertil throw farther than 21 meters, or if they throw equally far, then Jack wins.

\section*{Input}  
The first and only line of input contains the integers $A$ and $B$ ($0 \leq A,B \leq 30$), the number of meters Alice and Bertil threw.

\section*{Output}  

\begin{itemize}
  \item If Alice wins, print ``Alice''.
  \item If Bertil wins, print ``Bertil''.
  \item If Jack wins, print ``Jack''.
\end{itemize}
Note that you should not print the quotation marks.

\section*{Scoring}
Your solution will be tested on a set of test groups, each worth a number of points. Each test group contains a set of test cases. To get the points for a test group you need to solve all test cases in the test group.

\noindent
\begin{tabular}{| l | l | p{12cm} |}
  \hline
  \textbf{Group} & \textbf{Points} & \textbf{Constraints} \\ \hline
  $1$    & $20$       & $a \neq b$, $a,b \leq 21$ \\ \hline
  $2$    & $20$       & $a,b \leq 21$ \\ \hline
  $3$    & $20$       & Jack does not win. \\ \hline
  $4$    & $40$       & No additional constraints. \\ \hline
\end{tabular}
