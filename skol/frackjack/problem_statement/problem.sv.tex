\problemname{Frack Jack}
Alice och Bertil spelar ett spel som har en domare. De vill kasta en boll så nära 21 meter
som möjligt, men de vill inte överstiga 21 meter. De kastar alltid ett icke-negativt heltalsavstån.
Den som kastar närmst 21 meter vinner. Om båda kastar över 21 meter eller om de kastar lika långt så vinner domaren.

\section*{Input}  
Första raden innehåller två heltal $a$, $b$ ($0 \leq a,b \leq 30$).


\section*{Output}  

\begin{itemize}
  \item Om Alice vinner skriv ``Alice''.
  \item Om Bertil vinner skriv ``Bertil''.
  \item Om domaren vinner skriv, print ``Domare''.
\end{itemize}
Notera att du bör skriva ut utan citat tecken.
