\specialsection*{Competition rules for skolkvalet}
\begin{lista}
\item The competition takes place on a date determined by the school under {\bf four hours.
    No extra time is given for lunch or breaks.} Before the competition starts, the student
    shall decide together with the teacher whether they will use their own or a school computer.
    In both of these cases, the student must write skolkvalet in an agreed-upon location
    in the school.
    
\item The competition consists of six tasks that shall each be solved by using a computer
  program in your programming language of choice.
\item {\bf Input can be read into the program in any way}, e.g., through the program interacting
with the user (as in the sample runs in the tasks), being entered into a graphical interface,
or data files being sent to {\em standard input}. Just agree with your teacher on how the program will be tested.
\item Your solutions will be tested with prepared input data. Each task is typically tested
with 5 test cases, each awarding 1 point if your program outputs the correct answer within
an execution time limit of {\bf 3 seconds}. No input validation is required, as it adheres
to the specifications in the task.
\item There are often different constraints for the various test cases, such as the size of
the input or other limitations. These are specified in the task. {\bf Note that the difficulty
level of a task can vary significantly depending on these differences. Therefore, it might
be easier to score partial points on a seemingly difficult task than to score full points
on a seemingly easier task.} The information about partial scoring is thus extremely
important for planning your competition.
\item The grading is performed on the same or an equivalent computer as where the code was written.
Changes to the source code are not allowed after the competition. If the program cannot be
compiled, the task will be awarded 0 points.

\item If any of the following happens, 0 points are awarded on the particular {\em testcase} being tested,
  but the program shall still be tested on the rest of the testcases.
\begin{lista}
\item The execution time of the program exceeds 3 seconds \vspace{-0.2cm}
\item Execution error (run time error) \vspace{-0.2cm}
\item Wrong answer \vspace{-0.2cm}
\end{lista}

\item Participation is individual, which means, among other things, that no exchange
of ideas or files is allowed during the competition.  
\item Permitted resources: Any written material, material installed on the computer,
and material available on the internet. 
It is \ku{not} allowed to actively communicate on the internet (e.g., chatting or asking questions in a forum);
only searching for information is permitted.  
{\bf It is also not allowed to use generative AI such as ChatGPT or GitHub Copilot.}  
Calculators are allowed.  
\item Submissions must be made in the form of source code files (e.g., uppg1...uppg6 with appropriate
file extensions) uploaded to an agreed location. Other files will not be considered. Make sure to
submit the correct version of your program.  

The top performers in the qualifier advance to the finals in Gothenburg, where spots in the national team to
BOI in Finland and IOI in Uzbekistan are at stake.

\end{lista}

\specialsection*{Task 1 -- Frack Jack}

Alice and Bertil are throwing a ball in a park. Exactly $21$ meters in front of Alice and Bertil is a post, and Jack challenges Alice and Bertil to a little contest.

The challenge is for Alice and Bertil to each throw a ball as close to the post as possible, but the ball must not go past the post.
The one who throws closest to $21$ meters, without going past $21$ meters, wins. If both Alice and Bertil throw past $21$ meters, or if they throw the same distance, Jack wins instead. They have now thrown and need help to determine who won.

Write a program that first reads the numbers $A$ and $B$, the number of meters Alice and Bertil each threw.

It is guaranteed that $(0 \leq A,B \leq 30)$ holds.

Then the program should print who won: either `Alice'', `Bertil'', or ``Jack''. Note that you should not print the quotation marks.

\fe{Scoring:}\
The five test cases, each worth 1 point, have the following restrictions:
\begin{itemize}
\item[(1)] $\;\;\;\;$ $A \neq B$ and $A,B \leq 21$
\item[(2)] $\;\;\;\;$ $A, B \leq 21$
\item[(3)] $\;\;\;\;$ Jack did not win in this test case.
\item[(4-5)] $\;\;\;\;$ No additional restrictions.
\end{itemize}

\vspace{1cm}
\fe{Example Run 1}
\begin{verbatim}
Alice throw? 7
Bertil throw? 5

Answer: Alice
\end{verbatim}
\fe{Explanation:} Alice is closer to $21$, so she won.

\vspace{1cm}

\fe{Example Run 2}
\begin{verbatim}
Alice throw? 26
Bertil throw? 22

Answer: Jack
\end{verbatim}
\fe{Explanation:} Since both threw farther than $21$ meters, Jack won.

\specialsection*{Problem 2 -- Spinning Compass}

%\begin{center}
%  \includegraphics[width=12cm]{sifferkrypto.pdf} \ ~\
%  \ku{Example of a misunderstanding that can occur with Alice's new cipher.}
%\end{center}

You have a compass that can point in $360$ different directions. Right now it points straight up, at number $0$.

Unfortunately, the compass is broken, and the only way to make it point in other directions
is by lifting the entire compass and rotating it a number of degrees counterclockwise. To help you, you have
two robotic arms. These are unfortunately not perfect: the first robotic arm can
rotate the compass exactly $a$ degrees counterclockwise, and the second robotic arm can rotate $b$ degrees counterclockwise.
The robotic arms can only rotate the compass exactly $a$ or $b$ degrees each time
they are used, no more, no less.
Because of this, it may not be possible to make the compass point
in all $360$ directions.

This makes you wonder how many unique directions the compass can point in.
The compass can only be rotated by using the robotic arms multiple times.

Write a program that reads the numbers $a$ and $b$, the number of degrees that the first and second robotic arms rotate the compass.

It is guaranteed that $(1 \leq a,b \leq 360)$.

Then the program should output the number of unique directions the compass can point to if you rotate it multiple times using the robotic arms.

\fe{Scoring:}\
The five test cases, each worth $1$ point, have the following constraints:
\begin{itemize}
\item[(1)] $\;\;\;\;$ $a = 13$
\item[(2-3)] $\;\;\;\;$ $a = b$
\item[(4-5)] $\;\;\;\;$ No additional constraints.
\end{itemize}

\vspace{0.3cm}

\fe{Example Run 1}
\begin{verbatim}
Angle a ? 50
Angle b ? 180

Answer: 36
\end{verbatim}
\fe{Explanation:} With this set of robotic arms, the compass
can point to every integer multiple of $10$: $0, 10, 20, \dots, 350$.
For example, if she takes the arm with $a=50$ and uses it $8$ times, she can make the compass point $40$ degrees counterclockwise.

\vspace{0.4cm}

\fe{Example Run 2}
\begin{verbatim}
Angle a ? 360
Angle b ? 360

Answer: 1
\end{verbatim}
\fe{Explanation:} No matter how many times you rotate the compass with this set of robotic arms, it will continue pointing $0$ degrees counterclockwise.

\specialsection*{Problem 3 -- Arborist}

Teo has finally landed his dream job; he has started working as an arborist!
An important part of an arborist's work is planting trees.

Teo now needs help planting $N$ trees at integer positions along a number line.
The number line starts at position $0$, and the value increases by $1$ for each step to the right (and decreases by $1$ to the left).

For all $N$ trees, Teo has already decided the exact integer positions on the number line where they should be planted.
These positions are all positive integers.

Teo is currently at position $0$, together with $N$ large saplings.
To plant the trees, he can perform the following actions:
\begin{itemize}
\item Move one step to the right (increase position by $1$).
\item Move one step to the left (decrease position by $1$).
\item If he is at position $0$, pick up one of the $N$ saplings.
\item Take one of the saplings he is carrying and plant it at his current position.
\end{itemize}
Each such action takes exactly one second.

Unfortunately, Teo can carry at most $K$ kilograms of trees at a time.
Each tree weighs either $20$ or $40$ kilograms.

When all trees have been planted, Teo must also return to position $0$.
Your task is to calculate how long it takes for Teo to plant all the trees and then return to position $0$ if he works in the fastest possible way.

Write a program that first reads $N$ and $K$ ($1 \leq N \leq 8$, $20 \leq K \leq 50$), the number of trees to plant and the maximum weight Teo can carry.
Then read on the next line $N$ integers $x_1, \dots, x_N$ ($1 \leq x_i \leq 30$), the positions where each sapling should be planted.
On the last line, read $N$ integers $k_1, \dots, k_N$ ($k_i \leq K$), the weight of each tree sapling in kilograms.
The input thus describes $N$ trees numbered $1$ to $N$, where tree $i$ should be planted at position $x_i$ and weighs $k_i$ kilograms.
Each $k_i$ is either $20$ or $40$.

The program should then output the number of seconds it takes for Teo to plant all the trees and then return to $0$, assuming he does this in the fastest possible way.

\vspace{0.5cm}
\fe{Scoring:}\
The five test cases, each worth $1$ point, have the following constraints:
\begin{itemize}
\item[(1)] $\;\;\;\;$ $K=25$
\item[(2)] $\;\;\;\;$ $k_i = 20$ for all $i$.
\item[(3)] $\;\;\;\;$ All trees must be planted at the same position.
\item[(4-5)] $\;\;\;\;$ No additional constraints.
\end{itemize}

\vspace{1cm}

\begin{center}
{\LARGE Example runs are on the next page.}
\end{center}

\newpage

\fe{Example Run 1}
\begin{verbatim}
N and K ? 2 45
Tree positions ? 1 2
Tree weights ? 20 40

Answer: 10
\end{verbatim}
\fe{Explanation:} There are two trees in this example.
One tree weighs $20$ kilograms and should be planted at position $1$, and the other weighs $40$ kilograms and should be planted at position $2$.
In this example, an optimal solution for Teo is as follows:
\begin{itemize}
\item Pick up the tree to be planted at position $1$.
\item Move right.
\item Plant the tree at position $1$.
\item Move left.
\item Pick up the tree to be planted at position $2$.
\item Move right.
\item Move right.
\item Plant the tree at position $2$.
\item Move left.
\item Move left. He has now returned to position $0$ and is done.
\end{itemize}
There are other ways to plant the trees equally fast, but it cannot be done in
less than $10$ seconds.

\vspace{0.5cm}
\fe{Example Run 2}
\begin{verbatim}
N and K ? 4 42
Tree positions ? 10 9 7 8
Tree weights ? 20 40 20 20

Answer: 60
\end{verbatim}
\fe{Explanation:} In this example, an optimal solution is to first plant the tree at position $9$, then the ones at positions $10$ and $8$ in the same trip, and finally the one at position $7$.

\specialsection*{Problem 4 -- The Town Square}

The archaeologist Arvid is searching for an unknown Iron Age town square somewhere in central Sweden. He has mapped
a number of farms in the area and has concluded that the town square must be at the same distance
from the different farms.

The area Arvid has studied can be represented by a grid with $N$ rows and $M$ columns. It takes one minute for an
Iron Age person to move between two adjacent cells. Two cells are adjacent if they share one of their four sides.

You are given a map of the grid marking all farm positions.
It is known that it takes the same amount of time to reach the unknown town square from each of the farms.

Your task is to write a program that finds which cells could have contained the town square.

The program should first read the integers $N$ and $M$ ($1 \leq N,M \leq 10$), the number of rows and columns in the grid.
Then it should read $N$ rows with $M$ characters each, representing the grid.
The character ``\verb|*|'' indicates that there was a farm at that cell, and ``\verb|.|'' indicates that there was no farm.

It is guaranteed that there are at least two farms in the grid,
and it is guaranteed that there is always at least one cell where the town square can be.

The program should then output a copy of the input grid, but the cells where the town square could be located are marked with ``\verb|X|''.

\vspace{0.5cm}
\fe{Scoring:}\
The five test cases, each worth $1$ point, have the following additional constraints beyond those already mentioned:
\begin{itemize}
\item[(1)] $\;\;\;\;$ $N = 1$
\item[(2)] $\;\;\;\;$ There are exactly $4$ farms, all located at the corners of a rectangle.
\item[(3-5)] $\;\;\;\;$ No additional constraints.
\end{itemize}

\vspace{3cm}

\begin{center}
{\LARGE Example runs are on the next page.}
\end{center}

\newpage

\fe{Explanation of Example Run 1:}
The farms are in the first and last columns of the top row.
The third cell in the top row is two minutes from both farms (two steps left and two steps right).
All cells directly below it have the same distance to both farms: go up to the top row and then equally left or right.
Therefore, the entire column is marked with ``\verb|X|''. Other cells have different distances and are not marked.

\specialsection*{Problem 5 -- Long Stairs}

It is said that up in the Alps live $C$ sisters, each of whom has a favorite number $f$.
Each sister has therefore built a house $f$ height units above sea level.
The houses are built on an $R \times C$ grid, where the $x$-axis points east and the $y$-axis points north.
The first sister built her house at $(0,0)$, the second at $(1,0)$, and so on.
In other words, the houses are built along the bottom row of the grid.

Since the houses are so high up, it becomes difficult to go up and down.
Therefore, each sister has built a staircase from her house to the $R-1$ rows above.
For every step upward in the grid, the height decreases by $1$.
For example: if the sister’s house is at $(2,0)$ and has height $10$, then a stair step is built at $(2,1)$ with height $9$,
a step at $(2,2)$ with height $8$, and so on.

You are currently located on this grid.
More precisely, you are at coordinates $(s_x, s_y)$ and want to get to $(g_x, g_y)$.
You can move to cells adjacent up, left, down, or right.
It is never a problem to move left or right, even if there may be large height differences.
Naturally, you cannot move outside the grid.

High altitudes are quite tiring, so your goal is to minimize the time you spend at high height.
More precisely, if during your walk from $(s_x, s_y)$ to $(g_x, g_y)$ you visit some sequence of cells,
we define the difficulty of the walk as the sum of the heights of all cells you visit.
If you pass the same cell multiple times, each visit counts separately.
If you walk optimally, what is the minimum possible difficulty?

\begin{figure}[h]
\centering
\includegraphics[width=0.3\textwidth]{langatrappor_sample1.pdf}
\\The image shows what the grid looks like in Example Run 1.
The bottom row contains the sisters’ houses.
The start and goal are also marked, as well as the least tiring path between them.
\end{figure}

\begin{center}
{\LARGE The problem description continues on the next page.}
\end{center}

\newpage

Write a program that first reads the integers $R$ and $C$ ($1 \leq R \leq 10^9$, $1 \leq C \leq 10$),
the grid dimensions.
It should then read $C$ integers $f_1, \dots, f_N$ ($R-1 \leq f_i \leq 10^9$),
the height where each sister’s house is located.
$f_1$ is the height of the house at $(0,0)$, $f_2$ at $(1,0)$, and so on.

\textbf{Note} that the heights $f_i$ are chosen so that the remaining heights in the grid are never negative.

Then read the integers $s_x$ and $s_y$ ($0 \leq s_x < C$, $0 \leq s_y < R$),
the coordinates where you start.
Finally, read the integers $g_x$ and $g_y$ ($0 \leq g_x < C$, $0 \leq g_y < R$),
the coordinates you want to reach.

The program should then output the difficulty of the least tiring walk from the start to the goal coordinates.
\textbf{Note: the answer does not necessarily fit in a 32-bit integer.}

\fe{Scoring:}\
The five test cases, each worth $1$ point, have the following additional constraints:
\begin{itemize}
\item[(1)] $\;\;\;\;$ $C=2$
\item[(2-3)] $\;\;\;\;$ $R \leq 10^4$
\item[(4-5)] $\;\;\;\;$ No additional constraints.
\end{itemize}

\vspace{0.6cm}

\fe{Example Run 1}
\begin{verbatim}
R C ? 5 3
Bottom row ? 15 12 5
Start-x and start-y ? 0 0
Goal-x and goal-y ? 0 4

Answer: 61
\end{verbatim}

\fe{Explanation:} An image of this grid appears earlier in the problem description.
The least tiring route goes right, right, up, up, up, up, left, left.
The difficulty is $15+12+5+4+3+2+1+8+11=61$.

\specialsection*{Problem 6 -- Binary Palindromes}

Mikaela studies interesting positive integers, and now wants to investigate numbers that are \emph{binary palindromes}.
To formally describe this, we define the following functions:
\begin{align*}
\text{bin}(n) &= \text{the binary representation of the integer } n \text{ without leading zeros},\\
\text{reverse}(s) &= \text{the string } s \text{ written backwards}.
\end{align*}

An integer $n$ is thus a \emph{binary palindrome} if
\[
\text{bin}(n) = \text{reverse}(\text{bin}(n)).
\]

Note that a palindrome is a string that reads the same forwards and backwards.

Mikaela is particularly interested in binary palindromes that contain exactly $k$ ones in their binary representation,
and now wants to know how many such numbers exist in the interval $[l,r]$.

Given three integers $l$, $r$, and $k$, determine how many integers $x$ satisfy:
\begin{enumerate}
\item The number $x$ is between $l$ and $r$, i.e.\ $l \leq x \leq r$,
\item The number $x$ is a number Mikaela likes (i.e.\ a binary palindrome),
\item The binary representation of $x$ contains exactly $k$ ones.
\end{enumerate}

Write a program that reads the integers $l, r, k$ ($1 \leq l \leq r \leq 10^{18}, 1 \leq k < 60$).

The program should then output how many integers in the interval $[l, r]$ are binary palindromes and have exactly $k$ ones in their binary representation.

\fe{Scoring:}\
The five test cases, each worth $1$ point, have the following additional constraints:
\begin{itemize}
\item[(1)] $\;\;\;\;$ $l,r \leq 10^9$
\item[(2)] $\;\;\;\;$ $k \leq 4$
\item[(3-5)] $\;\;\;\;$ No additional constraints.
\end{itemize}

\vspace{2cm}

\fe{Example Run 1}
\begin{verbatim}
l r k ? 7 10 2

Answer: 1
\end{verbatim}

\vspace{1cm}

\begin{center}
{\LARGE The example runs continue on the next page.}
\end{center}

\newpage

\fe{Explanation of Example Run 1:}
We seek numbers in the interval $[7, 10]$ that are both binary palindromes and have exactly two ones in their binary representation.

There are only 4 numbers in the interval, and their binary representations are:

\begin{align*}
7 &= 111_2 \quad (\text{palindrome, three ones}) \\
8 &= 1000_2 \quad (\text{not a palindrome}) \\
9 &= 1001_2 \quad (\text{palindrome, two ones}) \\
10 &= 1010_2 \quad (\text{not a palindrome})
\end{align*}

The only number satisfying both conditions is $9$, so the answer is $1$.

\vspace{1cm}

\fe{Example Run 2}
\begin{verbatim}
l r k ? 1 6 2

Answer: 2
\end{verbatim}
\fe{Explanation:}
We seek numbers in the interval $[1, 6]$ that are both binary palindromes and have exactly two ones in their binary representation.

There are only 6 numbers in the interval:

\begin{align*}
1 &= 1_2 \quad (\text{palindrome, one one}) \\
2 &= 10_2 \quad (\text{not a palindrome}) \\
3 &= 11_2 \quad (\text{palindrome, two ones}) \\
4 &= 100_2 \quad (\text{not a palindrome}) \\
5 &= 101_2 \quad (\text{palindrome, two ones}) \\
6 &= 110_2 \quad (\text{not a palindrome})
\end{align*}

The numbers satisfying both conditions are $3$ and $5$, so the answer is $2$.

\vspace{1cm}

\fe{Example Run 3}
\begin{verbatim}
l r k ? 999 99999 6

Answer: 94
\end{verbatim}
