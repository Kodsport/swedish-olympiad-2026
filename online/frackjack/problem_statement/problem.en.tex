\problemname{Frack Jack}
Alice and Bertil are playing a game with a judge. They want to throw a ball as close as 21 metres 
as possible but not exceeding 21 metres. They always throw integer distance. The one closest to 21 wins. 
If Alice and Bertil both exceeds 21 metres or they thorw equal length then the judge wins.

\section*{Input}  
The first line of input contains the integers $a$, $b$ ($0 \leq a,b \leq 30$).


\section*{Output}  

\begin{itemize}
  \item If Alice wins, print ``Alice''.
  \item If Bertil wins, print ``Bertil''.
  \item If the judge wins, print ``Domare'', this translates to ``Judge''.
\end{itemize}
Note that you should not print the quotation marks.

\section*{Scoring}
Your solution will be tested on a set of test groups, each worth a number of points. Each test group contains
a set of test cases. To get the points for a test group you need to solve all test cases in the test group.
