\problemname{The Cat Necklace}
\noindent

\illustration{0.4}{Katthalsbandet.png}{Lulli, The Cat}

Louise loves her cat Lulli very much and therefore plants lots of catnip.

Now Louise wants to create a beautiful necklace for Lulli with $N$ charms placed in a ring.
On each charm there is exactly one symbol, either \texttt{(} or \texttt{)}.
The necklace also has a bell that marks where to start reading.

To make the necklace extra beautiful, Louise wants the necklace to be balanced.
For help, Louise hires a jeweler who can modify the necklace. As payment, she uses catmints.

The jeweler can remove any charm for a cost of $a$ catmints per charm.
The jeweler can also rotate the necklace one step, so that the first charm moves to the end, which costs $b$ catmints.
Louise is also satisfied if the necklace becomes completely empty, but then she must pay to remove each charm.

Louise therefore wants to make the necklace balanced at the lowest possible cost.

A necklace is balanced if its symbols, read in order from the bell, form a balanced parenthesis string.
A parenthesis string is balanced if:
\begin{itemize}
    \item It is empty, or
    \item It can be written as $AB$, where both $A$ and $B$ are balanced strings, or
    \item It can be written as $(A)$, where $A$ is a balanced string.
\end{itemize}


\section*{Input}
The first line contains three integers $N$, $a$ and $b$ ($1 \leq N \leq 5 \cdot 10^5$, $0 \leq a,b \leq 10^9$).

The second line contains a string $s$ of length $N$.
Each symbol in $s$ is either \texttt{(} or \texttt{)}.

\section*{Output}
Print one integer: the minimum possible total cost to make the necklace balanced.


\section*{Scoring}
Your solution will be tested on a set of test groups.
To earn points for a group, you must pass all test cases in that group.

\section*{Explanation of Samples}
In sample $1$, you can first rotate the necklace two steps.
\begin{center}

Then the necklace reads as \texttt{)(())}.
\begin{center}
\includegraphics[width=0.5\textwidth]{step1_rotate.png}
\end{center}
If you then remove the first charm, which is \texttt{)}, the necklace reads as \texttt{(())}, which is balanced.
\begin{center}
\includegraphics[width=0.5\textwidth]{step2_remove.png}
\end{center}
The total cost is $3 + 3 + 2 = 8$ catmints.

In sample $2$, you can remove the second charm, which is \texttt{)}, and then the last charm, which is \texttt{(}.
Then the necklace reads as \texttt{()()()}, which is balanced.
The total cost is $4 + 4 = 8$ catmints.

In sample $3$, you can rotate the necklace three steps, so that the necklace reads as \texttt{()()(())}.
It is already balanced, so the total cost is $3 + 3 + 3 = 9$ catmints.
